## AlgorithmsAndLeetCodeQuestions

It serves as a study log and reference for data structures, algorithms, and problem-solving techniques.
LeetCode solutions live under [solutions](./src/leetcode) (one folder per problem), and algorithms live under [algorithms](./src/algoritmos).
